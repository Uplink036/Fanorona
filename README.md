# FANORONA

## Introduction

FANORONA is a board game from Madagascar. It is played on a 9x5 grid of lines, with pieces placed on the intersections. The objective of the game is to capture all of the opponent's pieces by moving your pieces along the lines and jumping over the opponent's pieces.

This repo is an attempt to make a simple implementation of the game in Python. Then to make a reinforcement learning agent to play the game.
